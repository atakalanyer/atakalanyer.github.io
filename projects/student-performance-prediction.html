Project Overview

What it is

A regression project that predicts students' mathematics exam scores from demographic information, parental education, lunch type, test preparation and reading and writing scores. It is part of my 30 Days of Machine Learning learning journey.

The problem

Predict the math score (math score) of a student from the other information in the Students Performance in Exams dataset.

Why it matters

It is a compact problem for practicing the full workflow: EDA, encoding, scaling, model comparison and tuning.

Objectives

  • Explore the data and check for outliers.
  • Encode categorical variables and scale features.
  • Train and compare regression models.
  • Tune a Random Forest with cross-validation.
  • Understand which features carry the most signal.

Dataset Information

Source
Students Performance in Exams (Kaggle)
Rows
1,000 student records
Columns
5 categorical features, 2 numerical predictors and 1 target
Target
math score

Important features

  • Gender
  • Parental education level
  • Lunch type
  • Test preparation course
  • Reading score
  • Writing score

Data characteristics

  • Small dataset with no missing values reported.
  • Reading and writing scores correlate strongly with math score (0.8176 and 0.8026).

Methodology

  1. Data Collection

    Downloaded the dataset with KaggleHub and loaded it with Pandas.

  2. Exploratory Data Analysis

    Statistical summaries, missing-value check, distributions, IQR outlier inspection and correlation analysis.

  3. Data Preprocessing

    Ordinal encoding for parental education, one-hot encoding for other categories, StandardScaler, and a train / validation / test split.

  4. Model Development

    Linear Regression and Random Forest Regressor.

  5. Hyperparameter Optimization

    GridSearchCV with 5-fold cross-validation. Best parameters: n_estimators 100, max_depth 10, min_samples_split 2, min_samples_leaf 2.

  6. Model Evaluation

    MAE, MSE, RMSE and R². Linear Regression won on validation data and was used for the final test.

Key Findings & Insights

Simple beat complex

Linear Regression outperformed even the tuned Random Forest on validation data and was chosen as the final model.

About 88% of variance explained

The final test R² of 0.8804 means the model explains roughly 88% of the variance in math scores.

Reading and writing dominate

Both the correlation analysis and Random Forest importance point to these two scores as the strongest signals. Importance describes the model, not causes.

Challenges & Improvements

Technical challenges

  • Mixing ordinal and nominal categorical variables required different encodings.

Important decisions

  • Chose the final model on validation scores, then touched the test set once.
  • Kept Linear Regression even though the tuned Random Forest is more flexible.

Limitations

  • Only 1,000 records, so conclusions may not transfer to other student populations.
  • Reading and writing scores are strong predictors that would not exist before an exam.

Potential improvements

  • Try cross-validated model comparison for the linear model too.
  • Evaluate on a version of the problem that excludes reading and writing scores.
